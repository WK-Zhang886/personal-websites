# 个人排行榜

这是一个供个人使用的评分和排序网站，可以整理动漫、游戏、电影以及其他兴趣内容。

线上地址：[radiant-syrniki-8d8579.netlify.app](https://radiant-syrniki-8d8579.netlify.app/)

## 已有功能

- 创建和管理多张评分榜单
- 自定义等级名称、颜色和顺序
- 批量上传图片并生成统一封面
- 在等级间拖动并调整封面顺序
- 自动保存在当前浏览器
- 导出或导入完整备份
- 将当前榜单导出为 PNG 图片
- 支持展示模式和封面上传

## 使用说明

1. 新建一个榜单，并设置榜单名称。
2. 创建等级，按需要修改等级名称、颜色和顺序。
3. 添加项目和封面图片。
4. 通过拖动或上下按钮调整项目排名。
5. 使用导出功能保存完整备份，需要时再导入恢复。

## 本地运行

需要 Node.js 22.13 或更新版本。

```bash
pnpm install
pnpm dev
```

打开终端显示的本地地址即可使用。所有榜单和图片都存放在当前浏览器的 IndexedDB 中，不会上传到服务器。

## 数据说明

榜单和图片默认保存在当前浏览器的 IndexedDB 中。换电脑、换浏览器或清除浏览器数据后，内容不会自动同步，因此建议定期导出备份文件。

## 部署说明

网站前端可以部署到 Netlify 等静态托管平台。当前项目同时保留了 Netlify SPA 构建配置，适合后续从 GitHub 连接到 Netlify 自动部署。
