# 个人网站收藏夹

这是一个用于保存常用网站的个人收藏夹。可以按分类整理网址，也可以在浏览器中直接搜索和打开已保存的网站。

线上地址：[gleaming-moonbeam-720af0.netlify.app](https://gleaming-moonbeam-720af0.netlify.app/)

## 主要功能

- 按分类管理个人收藏
- 添加、编辑和删除网站条目
- 使用网站名称或网址搜索收藏
- 支持导出和导入收藏备份
- 支持手机和电脑浏览器访问

## 界面

新版保留动漫横幅，使用紧凑的网站卡片、直接显示的分类标签和一行收藏统计。导入、导出在页顶，网站卡片右下角的铅笔按钮用于编辑，右上角的星星用于置顶。

横幅使用 1536 × 1024 像素的 WebP 图片，约 199 KB，相比原 PNG 减少约 91% 的下载量，并在页面头部预加载。源码和部署包均使用压缩后的 WebP。

网站图标优先从原网站获取，失败后通过 [Favicon.im](https://favicon.im/api) 获取；无法获取、加载失败或超时时统一显示书签图标。图标加载期间也显示书签，不再用收藏名称的字母或数字代替图标。图标服务仅使用网站域名，不包含收藏名称、备注或分类；图标不会写入收藏备份。

这是一个纯前端静态网站，不需要服务器或数据库。收藏数据保存在当前浏览器的本地存储中。

## 本地运行

直接打开当前目录中的 `index.html` 即可使用。也可以使用任意静态文件服务器运行。

## 推荐免费发布方式：Netlify Drop

1. 打开 https://app.netlify.com/drop
2. 登录或注册 Netlify
3. 把当前网站文件夹或 `publish` 文件夹拖进去
4. 等待部署完成，Netlify 会生成一个公网网址
5. 手机打开这个网址即可使用

### 更新现有 Netlify 网站

`publish` 文件夹和 `personal-bookmark-site-publish.zip` 都是本次更新后的部署文件。进入原有 Netlify 项目的 Deploys 页面，将 `publish` 文件夹上传即可更新；使用压缩包时先解压，上传包含 `index.html` 的文件夹。

继续使用原来的网址和浏览器，原有收藏会继续读取。部署文件不包含个人收藏数据；可以在更新前用页面右上角的“导出”保存一份备份。若更新后仍显示旧样式，可按 `Ctrl + F5` 强制刷新。

## 数据说明

收藏数据保存在浏览器本地。发布到网上以后：

- 电脑浏览器和手机浏览器的数据不会自动同步
- 可以在电脑上点“导出”，在手机上点“导入”
- 每个访问者看到的是自己浏览器里的收藏数据

## 项目文件

- `index.html`：网站页面
- `styles.css`：页面样式
- `app.js`：收藏夹交互逻辑
- `assets`：网站使用的图片资源
